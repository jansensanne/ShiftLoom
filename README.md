# ShiftLoom

ShiftLoom is a high-performance, distributed fabric engine that enables real-time auto-scaling of complex network computations.

ShiftLoom is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ShiftLoom.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
